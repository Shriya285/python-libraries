# Python for Data Analysis — Practice Notebooks

Personal practice notebooks covering the core Python data stack: NumPy, Pandas, and data visualization with Matplotlib/Seaborn.

## 📂 Contents

| Notebook | Covers |
|---|---|
| `numpy_tut.ipynb` | NumPy fundamentals — array creation, indexing, reshaping, and vectorized operations |
| `pandas.ipynb` | Pandas fundamentals — DataFrames, Series, selection, cleaning, and grouping |
| `data_visualization_seaborn_matplotlib.ipynb` | Plotting with Matplotlib and Seaborn — line plots, styling, and statistical charts |

## 🛠️ Tech Stack

- Python 3
- NumPy
- Pandas
- Matplotlib
- Seaborn

## ▶️ Running Locally

```bash
git clone <repo-url>
cd <repo-folder>
pip install numpy pandas matplotlib seaborn jupyter
jupyter notebook
```

## 📌 Notes

These are learning/practice notebooks, not a packaged project — code and comments reflect working through core concepts in each library rather than a finished analysis.
